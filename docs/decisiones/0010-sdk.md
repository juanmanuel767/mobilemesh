# Decisión 0010: SDK para desarrolladores (Fase 12)

Fecha: 13-10-2026 · Estado: aceptada

## Decisión

| Tema | Elección | Por qué |
|---|---|---|
| Forma | Módulo de Android `mobilemesh-sdk` con el núcleo (Rust), la protección de la clave (Keystore), el servicio en segundo plano y una API sencilla en español | Un programador lo añade como dependencia y no toca Rust, claves ni red. |
| API | `MobileMesh.iniciar`, `coleccion(...).guardar/leer/todos/borrar/escuchar/compartirCon`, contactos, mensajes, archivos, recuperación, relé, diagnóstico | Lo equivalente a lo que se usa a diario en Firebase o Supabase. |
| Valores | Texto, números y booleanos (guardados como JSON dentro de cada campo cifrado) | Tipos básicos sin dependencias nuevas. |
| Tiempo real | `escuchar` avisa cuando cambia algo (comprueba cada segundo) | Simple; mejorable con avisos del núcleo. |
| Errores | Todos son `MobileMeshError` con mensaje en español | Coherentes y listos para mostrar. |
| Varias apps en un teléfono | Cada una elige su puerto | Antes chocaban por el mismo puerto. |
| Colecciones compartidas | Se sincronizan solas con cada contacto que las comparte | Como el tiempo real de Firebase, sin servidor. |

## Criterio de la fase: cumplido

Una app **independiente**, `examples/notas` («Notas compartidas», ~90 líneas, sin Firebase ni
Supabase), instalada en el TECNO y en el nubia con **cuentas distintas** (como dos personas):
se pasaron la invitación, compartieron sus notas y cada nota escrita en un teléfono apareció sola en
el otro (una nota nueva tardó 4 s). Al reiniciar la app las notas siguen ahí.

La app de pruebas grande también usa ya la librería y siguió funcionando (conservó la cuenta y
recibió mensajes).

## Encontrado y corregido

- Sin red, la invitación salía con la dirección `0.0.0.0`; ahora da un error claro.

## Pendiente

- Publicar la librería en un repositorio de Maven para añadirla con una sola línea.
- iPhone (Swift) y navegador (WebAssembly) con el mismo núcleo.
- Consultas con filtros y orden; avisos de cambios desde el núcleo en vez de comprobar cada segundo.
